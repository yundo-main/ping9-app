# E6.1 — 레슨 콘텐츠 추가 + 토폴로지 썸네일 + UX 계획

- Task: E6.1 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

커리큘럼 dev-plan의 N2·N3·N6 레슨을 JSON 콘텐츠로 추가하고, 레슨 카드에 네트워크 그림(토폴로지 썸네일)을 붙이고, UX 개선 계획을 문서로 정리한다.

## 진행 방식·결과

### 새 레슨 (edu/core/src/lessons/*.json)

| 파일 | 단원 | 핵심 check |
|---|---|---|
| n2-arp-watch.json | n2-arp | ARP 주소 사전 설정 → ping → 추적에서 `ARP_REQUEST_SENT`+`ARP_ENTRY_LEARNED` 관찰 |
| n3-vlan-split.json | n3-vlan | 4대 PC 한 스위치 → VLAN 10/20으로 분리 → 같은 VLAN ping 성공 + `VLAN_BLOCKED` 추적 |
| n6-router-gateway.json | n6-routing | 라우터 두 인터페이스 주소 + PC 게이트웨이 → 다른 서브넷 ping + `IPV4_FORWARDED` 추적 |

- defineLesson이 로드 시점에 스키마·토폴로지·check를 검증 — 잘못된 데이터는 앱 시작 전에 걸러진다.
- `VLAN_BLOCKED`는 forwarding.ts에서 access 포트가 다른 VLAN 프레임을 차단할 때 기록되는 DROP 코드 — 교차 VLAN ping 시도가 곧 채점 증거가 되는 구조.
- UNIT_TITLES에 N1–N12 전 단원 이름을 등록해 새 단원 카드가 사람 이름으로 보이게 함.

### 토폴로지 썸네일 (그리드)

- `topology-thumb.tsx` 신설 — startDocument의 장비 position·links를 미니 SVG로 정규화 렌더 (장비 종류별 파스텔 색 + 약자 라벨 + 이름).
- 레슨 카드 상단에 삽입 — 카드만 봐도 어떤 네트워크를 만지는지 보인다.

### UX 개선 계획

- `edu/docs/ux-plan.md` — designed-to-scale 경험 기준으로 P1(학습 마찰)·P2(정보 밀도)·P3(교사 흐름)·P4(기술) 13개 후보와 당장 안 할 것을 정리.

## 계획과 달라진 점
