# E6.3 — designed-to-scale UX 적용 (level·minutes·goals·callout)

- Task: E6.3 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

참고 사이트(designed-to-scale.vercel.app)의 레슨 스키마를 번들에서 추출해, 그 UX 요소를 edu 레슨에 적용한다.

## 참고 사이트 스키마 (번들 분석 결과)

`Ze={id, title, summary, minutes:12, level:'beginner', metrics:[...], legend:[...], goals:[{text, step:1}...], steps:[{short, chapter:'problem'|'solution', title, body:[...], callout:{kind:'warn'|'tip', text}, metrics:{...}, scene:{entities,links,flows}}]}`

## 진행 방식·결과

- `lesson.ts` 스키마 확장: 레슨에 `level`(beginner/intermediate/advanced)·`minutes`·`goals[{text, step}]`, 단계에 `short`·`chapter`·`callout{kind:tip|warn|note, text}` — 전부 optional이라 기존 레슨 호환 유지.
- 4개 레슨 JSON에 난이도·소요시간·학습 목표·단계 제목·강조 박스 기입 (목표의 step은 1-based 단계 번호).
- 플레이어: 헤더에 난이도 배지+~N분, 브리프 상단에 **학습 목표 리스트**(클릭하면 해당 단계로 이동·현재 단계 하이라이트), 단계 카드에 챕터 eyebrow+제목+callout 박스, 스텝 도트에 툴팁.
- 목록 카드: 난이도 배지 + 소요 시간 메타.
- `scene`(애니메이션 다이어그램)과 `metrics`는 미적용 — 우리의 "scene"은 라이브 시뮬레이터라 대응물이 없음. 대신 목표→단계 점프로 단계-화면 연결의 일부를 흉내냄.
