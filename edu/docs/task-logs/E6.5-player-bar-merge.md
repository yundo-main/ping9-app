# E6.5 — 플레이어 헤더를 본체 topbar 안으로 통합 (한 행)

- Task: E6.5 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

레슨 플레이어의 edu 상단 바와 EditorApp의 펭귄 로고 topbar를 같은 색으로 맞추는 것을 넘어, 아예 **한 행**으로 합친다. 둘은 다른 React 트리라 CSS만으로는 불가 — topbar에 슬롯 seam을 연다.

## 진행 방식·결과

### 코어 (packages/editor)

- `TopBar`에 `start`/`end` ReactNode 슬롯 추가 — start는 브랜드·crumb 사이, end는 spacer 뒤(오른쪽 버튼열 앞).
- `TopBar.crumb?: boolean` (기본 true) — false면 토폴로지 이름·파일명 영역을 그리지 않음.
- `EditorAppProps`에 `topbarStart`/`topbarEnd` 추가, `EditorFeatures`에 `crumb` 플래그 추가.
- 기존 컨벤션 유지: optional prop 없으면 그리지 않음 (onHelp·onReset·fileActions와 같은 패턴).

### edu 쪽

- `.edu-player-bar` 헤더를 통째로 제거 — `.edu-player`가 한 행(grid-template-rows: 1fr)만 가짐.
- `topbarStart` = `← 목록` + 단원명 + 레슨 제목 + 난이도 배지 + ~N분 (crumb 자리를 대체).
- `topbarEnd` = 내보내기·가져오기(숨은 file input)·과제 닫기/보기·채점하기.
- `features={{fileActions:false, crumb:false}}` — 본체의 파일 버튼과 "토폴로지" crumb 숨김.
- 새 `.edu-tb-*` 스타일 — topbar의 ghost 버튼과 같은 반투명 흰색 계열. 채점하기는 시안 팝 유지.

### 결과 헤더 (한 행)

`[펭귄 PING9 | ← 목록 단원 제목 [초급] ~5분 | … | 내보내기 가져오기 과제 닫기 채점하기 | 리셋 ? | 실시간/시뮬레이션]`

## 계획과 달라진 점

- 처음엔 CSS 그라데이션 통합(두 행)으로 접근했다가 사용자 요청으로 한 행 통합으로 방향 전환 — 같은 Task 안에서 슬롯 seam으로 재구현.
