## 목표

1. 펭귄 대신 네트워크 장비(라우터·스위치·PC 등)를 3D로 — 레슨 카드 썸네일을 실제 토폴로지의 3D 장면으로.

- `topology-thumb-3d.tsx` — three.js로 startDocument를 3D로 렌더: 장비 종류별 프리미티브 모델(PC=모니터+받침, 스위치/L3/허브/LB=포트 박스, 라우터=안테나 박스, 서버=타워, 클라우드=구체 덩어리), 링크는 얇은 원기둥, 8각 얼음 판 위에 천천히 도는 턴테이블.
- 레슨 카드에서 `React.lazy`+`Suspense`로 지연 로딩 — 로드 중엔 기존 SVG `TopologyThumb`이 폴백.
- `topbarEnd`에서 이메일·로그아웃 블록 제거(대시보드 링크만 남김) → `.edu-brief` 하단에 sticky 사용자 블록(이메일+로그아웃) 추가.
