# E6.2 — 핑구 테마 변환 + 도트 그리드

- Task: E6.2 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

E5.1의 designed-to-scale 종이(크림) 테마를 본체 핑구 UI의 sky/ice/navy/beak 팔레트로 교체하고, 시뮬 캔버스와 같은 도트 그리드를 페이지 배경에 넣는다.

## 진행 방식·결과

- `index.css` `:root` 변수 재매핑 — 색만 바꾸고 구조(팝 버튼·칩·틱 리스트)는 유지:
  - 배지 `--green` 연두 → `--cyan #8fdcff` 팽귄 배색, hover `#6fcdf9`
  - 잉크 `#1d1b18` → 네이비 `#262a47`, muted → `#5a6385`, 라인 → `#c9dcf5/#9dbde8`
  - 팝 그림자 검정 → 딥블루 `#0e3a7a`, 카드 그림자 → 부드러운 파란 그림자
  - 코드 블록 배경 잉크 → 터미널 navy `#0e1b38`
- `body` 배경에 `radial-gradient(circle, #c4dbf7 1.4px …) 24px` — editor.css `.canvas`의 도트 그리드와 같은 패턴, fixed
- 본문 폰트 JetBrains Mono → Pretendard 계열 (`--sans`), 코드·썸네일 텍스트만 `--mono` 유지 — `index.html`에 Pretendard CDN 추가 (apps/web과 같은 CDN)
- `topology-thumb.tsx` 장비 채움색 → ice 팔레트 (PC=#d3e6fc, SW=#8fc4fa, R=#fcdcbd 부리색 등)
- 남아 있던 따뜻한 하드코딩 색(`#503c23`, `#d97a4f`, `#b85c1e`, `#2f8a43`) → 파란/부리 톤으로 교체
