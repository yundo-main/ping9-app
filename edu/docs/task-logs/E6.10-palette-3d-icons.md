# E6.10 — 팔레트 도구 3D 아이콘 (edu 전용 seam)

- Task: E6.10 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

레슨 플레이어의 장비 팔레트(PC·Server·Switch·Router·Cloud …) 아이콘을 3D로 — E6.9의 썸네일 모델과 같은 세계관으로.

## 진행 방식·결과

- `features.icons3d` seam 추가 (EditorFeatures) — 켜진 셸만 팔레트 아이콘이 3D가 된다. 본체 web/데스크톱은 기존 SVG 그대로.
- `device-models-3d.ts` (editor) — 장비 종류별 three.js 모델 공장. edu의 `topology-thumb-3d.tsx`에서 옮겨와 썸네일·아이콘이 한 소스를 쓴다. `@ping9/editor/device-models-3d` subpath export로 노출(index로 넣으면 three가 메인 번들에 들어감).
- `device-icon-3d.tsx` (editor) — 장비 종류마다 오프스크린 WebGL로 한 번씩만 그려 PNG data URL로 캐시해 `<img>`로 붙임. 도구마다 살아 있는 WebGL 캔버스를 두지 않아 저렴. 로드 중엔 기존 SVG 아이콘 폴백.
- 팔레트는 `React.lazy`+`Suspense`로 아이콘 모듈을 불러 three가 별도 청크로 빠진다 — icons3d를 켜지 않은 앱은 청크를 요청하지 않는다.
- `three`를 `@ping9/editor` dependencies에 추가(`@types/three` dev). edu lesson-player에 `icons3d: true`.

## 후속 — 플래그 해제 (같은 날)

판단: 팔레트 아이콘은 원래 2D가 낫다는 요청으로 edu의 `features.icons3d`를 끔. seam과 3D 코드(모델 공장·스프라이트 렌더러)는 그대로 두고 edu만 플래그를 내린다 — 썸네일 3D는 유지.
