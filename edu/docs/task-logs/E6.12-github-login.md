# E6.12 — GitHub OAuth 로그인

- Task: E6.12 | 일자: 2026-11-26 | 브랜치: main | 커밋: 14e2102

## 목표

Google에 이어 GitHub 소셜 로그인을 지원한다.

## 진행 방식·결과

- `auth.ts`의 `signInWithGoogle`을 `signInWithProvider(provider)`로 일반화하고 `signInWithGithub` 추가 — provider만 다르고 동일 경로(`signInWithOAuth` + `redirectTo: origin`)
- 로그인 페이지에 "GitHub로 계속" 버튼 추가 (Google 버튼과 같은 스타일)
- Supabase 쪽은 `site_url`·리다이렉트 허용 목록이 이미 설정돼 있어 provider 토글 + 자격증명만 넣으면 된다

## 남은 것 (코드 외)

1. GitHub OAuth App 생성 (github.com/settings/developers → New OAuth App): callback = `https://etquisloivqtbjjdbduk.supabase.co/auth/v1/callback`
2. Supabase 대시보드 → Authentication → Providers → GitHub → Client ID/Secret 입력
3. Google도 같은 상태 — provider는 켜져 있고 자격증명 입력이 동작 조건 (E4.4)
