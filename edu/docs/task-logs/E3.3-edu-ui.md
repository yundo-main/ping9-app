## 1. 목표와 완료 기준

- [x] 진도 표시 — 전체/단원 진행률 바, 카드 완료 배지 (localStorage)

- [x] 브리프 마크다운 — 코드 블록·인라인 코드·굵게·목록·제목

## 2. 진행 방식

1. `progress.ts` — 통과한 레슨 id 집합을 localStorage에 둔다 (E4.2에서 DB로 옮길 자리)
2. `lesson-list.tsx` — 전체 진도 바 + 단원별 "n/m 완료" + 카드 완료 배지
3. `lesson-player.tsx` — `<Markdown>`으로 브리프 렌더, 채점 결과 "n/m 통과", 통과 시 진도 기록 + 다음 레슨 버튼, 브리프 접기 토글
4. `markdown.tsx` — 하위 집합 렌더러 (제목·fenced 코드·`inline`·**굵게**·목록·단락). 의존 없이 70줄
5. `app.tsx` — 해시 라우팅 (`#` push 없이 `location.hash` 교체 + hashchange 구독)

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 해시 라우팅 | 경로 라우팅은 Vercel SPA rewrite 설정이 필요하고 정적 배포라 해시가 무설정으로 동작한다 | react-router + 경로 라우팅 — 의존 + 서버 설정 |
| 자체 마크다운 렌더러 | 브리프는 저작자 입력이라 하위 집합이면 충분 — marked/react-markdown 의존을 늘릴 이유가 없다 | 마크다운 라이브러리 — 번들·버전 관리 추가 |
| 진도를 localStorage에 | E4.2(DB) 전에 진도 체감을 먼저 제공 — 스키마가 단순해서 이관이 쉽다 | DB 먼저 — Supabase 프로젝트가 아직 없다 |
