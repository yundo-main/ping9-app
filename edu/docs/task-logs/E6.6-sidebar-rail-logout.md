# E6.6 — 사이드바 핑구 레일 + 플레이어 로그아웃

- Task: E6.6 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

1. 왼쪽 사이드바(과제 패널)를 펭귄 topbar에서 이어지는 파란 세로 레일로 만든다.
2. 한 행 통합 후 플레이어에 없던 로그아웃 버튼을 topbar에 추가한다.

## 진행 방식·결과

- `.edu-brief` 배경을 `linear-gradient(180deg, #0b4fc4, #0e3a7a)`로 — topbar 왼쪽 끝(sky-900)과 같은 색에서 시작해 아래로 어두워지는 세로 기둥. 텍스트·목표·단계 버튼·도트·힌트·마크다운 코드를 밝은 색 계열로 재색 (`.edu-brief` 스코프 한정, 다른 화면의 기본 규칙은 유지). callout은 밝은 배경 카드로 대비 유지.
- `topbarEnd` 끝에 세션 표시 + 로그아웃 버튼 추가 — 게스트는 "게스트", 비로그인은 `로그인` 링크로 `#/login` 이동.
