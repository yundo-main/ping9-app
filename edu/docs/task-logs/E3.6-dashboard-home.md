## 1. 목표와 완료 기준

- [x] 로그인한 사용자가 루트로 들어오면 `#/dashboard`가 홈
- [x] 레슨 목록은 로그인 여부와 무관하게 `#/lessons`에서 항상 접근 가능
- [x] 공통 완료 조건 (typecheck·build·check:secrets)

## 2. 진행 방식

1. `app.tsx` 라우트 정리 — `#/lessons`를 명시 라우트로 추가, 목록 JSX를 `list` 변수로 빼 두 라우트(`#/lessons`·게스트 루트)가 공유
2. 루트(`""`·`#`·`#/`)와 알 수 없는 해시 → `sessionReady && session`이면 `#/dashboard`로 이동, 게스트는 목록 표시
3. 이동 경로 정리 — 대시보드 "← 레슨 목록"·인증 페이지 뒤로가기·레슨 종료(`openLesson(null)`)가 전부 `#/lessons`를 가리키게

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 목록에 `#/lessons` 명시 라우트 | 로그인 사용자의 루트가 대시보드라 목록이 주소 없이 남으면 못 돌아간다 | 루트를 세션으로 양쪽 재사용 — 로그인 사용자가 목록으로 못 감 |
| 레슨 종료 → `#/lessons` | 종료 후 목적지가 "목록"이라는 의도가 코드에 드러남; 로그인 사용자가 루트로 보내지는 함정도 없앰 | `""`로 돌리기 — 로그인 사용자는 대시보드로 튐 |

## 3. 결과

- 흐름: 게스트 = 루트(목록) → 레슨 / 로그인 → `#/dashboard` → 레슨 / 로그인 사용자의 루트 재방문도 대시보드
- `#/dashboard`에 비로그인 접근 시 `#/login` 유도는 그대로
- typecheck·build·check:secrets 통과
