## 2. 진행 방식

Management API `/config/auth`로 설정 — 대시보드 클릭 없이 코드로:

| 설정 | 값 |
|---|---|
| `site_url` | `https://ping9-edu.vercel.app` — OAuth 후 돌아올 기본 주소 |
| `uri_allow_list` | `https://ping9-edu.vercel.app/**`, `http://localhost:5173/**`, `http://localhost:5174/**` — 배포·로컬 개발 둘 다 허용 |
| `external_google_enabled` | `true` — provider 슬롯을 켜 둠 (client_id는 비어 있어 입력 대기) |

함정: `uri_allow_list`에 줄바꿈 구분으로 보내면 구분자가 날아가 한 덩어리로 저장됐다 — 쉼표 구분으로 다시 보내 해결.

## 3. 결과

- 코드 쪽은 처음부터 준비돼 있었다: `signInWithGoogle()`이 `signInWithOAuth({provider:"google", redirectTo: origin})` — 버튼도 로그인/가입 화면에 있음
- 남은 사용자 작업: Google Cloud Console에서 OAuth 클라이언트(웹) 만들고 리다이렉트 URI `https://etquisloivqtbjjdbduk.supabase.co/auth/v1/callback` 등록 → Client ID/Secret을 Supabase 대시보드(또는 Management API)에 입력
- edu/README.md에 "Supabase Auth 설정" 절 추가
