# E6.7 — "PING9에 관하여" 제품별 내용 + 로그아웃 후 복귀

- Task: E6.7 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

1. edu에 임베드된 AboutDialog가 본체 시뮬레이터 설명만 보이던 것을 제품별로 바꿀 수 있게 한다.
2. 로그아웃하면 첫 화면(로그인)으로 돌아가게 한다.

## 진행 방식·결과

### About 제품별 내용 (코어 seam)

- `AboutDialog`에 `desc?`·`extra?: ReactNode` props 추가 — desc는 한 줄 설명 교체, extra는 크레딧 끝에 붙는 제품별 섹션.
- `EditorAppProps`에 `aboutDesc`/`aboutExtra` 추가해 전달.
- edu는 `aboutDesc="네트워크 진도별 학습도구 — PING9 엔진 위의 커리큘럼·과제·자동 채점"`과 "교육용 웹 — ping9-edu.vercel.app" 크레딧을 넘긴다. web은 props 없이 기존 내용 유지.

### 로그아웃 복귀

- `app.tsx`에 `logout()` 추가 — `signOut()` 후 `#/login`으로 이동. 목록·학생 대시보드·교사 대시보드 모두 이걸 쓴다.
- `lesson-player`의 topbar 로그아웃도 `signOut()` 후 `#/login` 이동 — 레슨은 비로그인도 열리지만 로그아웃의 기대 행동은 로그인 화면 복귀로 통일.
