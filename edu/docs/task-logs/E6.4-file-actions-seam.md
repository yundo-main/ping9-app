# E6.4 — 코어 features seam + edu 파일 버튼 통합

- Task: E6.4 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

edu가 EditorApp을 통째로 임베드하면서 본체 TopBar의 내보내기·가져오기 버튼이 그대로 노출되던 문제를 해결 — 파일 UI를 edu 플레이어 바로 통합한다.

## 진행 방식·결과

### 코어 (packages/editor) — 새 seam

- `EditorAppProps.features?: EditorFeatures` 추가 — `fileActions:false`면 TopBar의 파일 버튼을 그리지 않는다. core-sharing.md의 "열어 둔 seam 후보"에 있던 `features` prop을 실제로 열었다.
- TopBar의 `onExport`/`onImport`를 optional로 — `onHelp`/`onReset`과 같은 기존 컨벤션(없으면 버튼을 그리지 않음)을 따른다. 어느 한쪽만 끄는 것도 가능.
- `MenuActions`는 features와 무관하게 항상 노출 — 버튼을 숨겨도 `onActions`로 동작 자체는 쓸 수 있다.
- `EditorFeatures` 타입을 index.ts에서 export.

### edu 쪽

- `LessonPlayer`가 `onActions`로 `MenuActions`를 받아 ref에 보관, `features={{fileActions:false}}`로 본체 버튼 숨김.
- 플레이어 바에 자체 `⤓ 내보내기`/`⤒ 가져오기` 버튼 + 숨은 `<input type=file>` — 내보내기는 `download` prop 미지정이라 브라우저 다운로드, 가져오기는 본체의 확인 대화(needsReplaceConfirm)가 그대로 동작.

## 계획과 달라진 점

- 가져오기는 레슨 시작 토폴로지를 덮어쓰지만 본체가 대체 확인 대화를 띄우므로 별도 제한을 두지 않았다. DB 진행 상태 저장은 별도 Task (ux-plan P1)로 유보.
