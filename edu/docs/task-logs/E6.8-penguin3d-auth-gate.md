# E6.8 — 3D 펭귄 + 로그인 필수 게이트

- Task: E6.8 | 일자: 2026-12-22 | 브랜치: main | 커밋: (작성 시점 미커밋)

## 목표

1. 로고 펭귄의 3D 버전을 코드로 직접 만들어 로그인 화면에 띄운다.
2. 로그인(계정·게스트) 없이는 서비스의 어떤 화면도 쓸 수 없게 한다.

## 진행 방식·결과

### 3D 펭귄 (penguin-3d.tsx)

- three.js 프리미티브로 납작한 로고 캐릭터를 재현 — 네이비 구 몸통, 흰 타원 배, 흰 눈+검정 눈동자, 주황 원뿔 부리, 양옆 날개, 주황 발, 7각 기둥 얼음 빙판. 조명 3개(주변광·키·시안 림).
- 천천히 좌우로 회전(sin)·위아래로 떠다니며 날개가 파닥인다. `alpha:true` 배경 투명.
- `React.lazy`+`Suspense`로 지연 로딩 — three(~150KB gzip)가 `penguin-3d-*.js` 별도 청크로 분리돼 로드 중엔 기존 2D 로고가 폴백으로 보인다.
- 로그인·가입 카드에서 로고 이미지 자리에 배치 (170px).

### 로그인 필수

- `app.tsx` 라우팅 앞부분에 게이트: `#/login`·`#/signup`이 아니면 `sessionReady`까지 대기 → `session === null`이면 `#/login`으로 보낸다. 게스트 세션은 통과하므로 "게스트로 시작하기"가 무료 입구로 남는다.
- 목록·레슨·대시보드 전부 세션 필요로 통일 — 목록의 비로그인 "로그인" 링크·대시보드의 비로그인 리다이렉트·마지막 AuthPage 폴백 등 죽은 분기 정리.
- AuthPage의 `onBack`("← 목록으로") prop·버튼 제거 — 비로그인 상태에선 돌아갈 목록이 없어 무한 리다이렉트가 됐을 것.
