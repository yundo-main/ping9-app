# PING9 Edu UX 개선 계획

기준: designed-to-scale.vercel.app의 코스 경험(종이 테마·카드 그리드·단계 진행)을 우리 학습 흐름(로그인 → 대시보드 → 레슨 → 채점)에 맞춰 다듬는다. 2026-12-22 작성.

## 현재 상태

- 첫 화면 = 로그인(로고) → 게스트/계정 → 대시보드 → 레슨 플레이어(단계 안내 + 임베디드 시뮬레이터) → 채점
- 진도는 계정 DB 저장, 교사는 반·과제·막힘 분석
- 레슨 카드에 토폴로지 썸네일(미니 SVG) — 이번에 추가

## 개선 후보 (우선순위)

### P1 — 학습 흐름의 마찰 줄이기

| # | 항목 | 근거 | 규모 |
|---|---|---|---|
| 1 | **레슨 내 이탈 시 진행 상태 보존** — 어디까지 설정했는지 나가면 날아감 | 중간 저장 없으면 재진입이 좌절 | 중 (startDocument 델타 저장) |
| 2 | **채점 자동 실행** — 조건이 바뀔 때 자동 재채점 또는 "n/m 조건 충족" 실시간 표시 | 수동 버튼 반복이 번거로움 | 중 |
| 3 | **실패 피드백 연결** — 실패한 check가 캔버스의 해당 장비로 안내(하이라이트) | "뭐가 틀렸지"를 찾는 게 학생 | 중 |
| 4 | **다음 레슨 추천 카드** — 대시보드 resume가 지난 활동 단원을 우선 | 이어서 학습의 정확도 | 소 |

## 지금 당장 하지 않는 것

- 게임화(배지·XP·리더보드) — 콘텐츠가 먼저
- 다국어 — 레슨 JSON 구조는 이미 로케일 확장 가능, 한국어만 유지
- 레슨 잠금(순서 강제) — 자유 진행 유지, 반 단위 잠금은 수요 확인 후
