PING9

네트워크 장비를 배치·연결하고 CLI로 설정해
통신의 과정과 실패 원인을 눈으로 확인하는 시뮬레이터

다운로드 (macOS · Windows) GitHub 저장소

기능

장비 배치·연결

PC, 서버, 스위치(L1 허브·L2·L3·L4/7 LB), 라우터를 캔버스에 끌어 놓고 케이블로 잇습니다. 범위 선택·실행취소(⌘Z)·토폴로지 내보내기/가져오기를 지원합니다.

실제와 닮은 CLI

라우터는 Cisco IOS·VyOS·Linux 형식 셋 중에서 고릅니다. enable → configure terminal → interface 흐름, 명령 줄임말, 도움말까지 실습할 수 있습니다.

서비스와 클라이언트

서버마다 HTTP·DNS·FTP·NTP·SSH를 켜고 끄고, 파일 목록·DNS 레코드·SSH 계정·stratum을 설정합니다. PC 콘솔에서 curl·nslookup·ntpdate·ssh로 확인합니다.

패킷 흐름이 보인다

ping 한 번이 ARP 요청부터 회신까지 어떤 경로로 오가는지 추적하고 재생합니다. 어느 장비가, 어떤 이유로 패킷을 버렸는지도 보여줍니다.

라우팅·방화벽·VPN

정적 경로, RIP 경로 교환, iptables 필터, GRE/IPsec 터널, L3 스위치 SVI 라우팅까지 — 수업에서 다루는 실습 범위를 그대로 옮겼습니다.

설치 없는 데스크톱 앱

Tauri로 만든 macOS·Windows용 단일 앱. 네트워크·계정 없이 바로 켜서 씁니다.
