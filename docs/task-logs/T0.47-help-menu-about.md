# T0.47 — Help 메뉴에 PING9에 관하여 항목

## 한 일

비어 있던 Help 메뉴에 "PING9에 관하여" 항목을 넣었다. 앱 메뉴(PING9)의 같은 항목과 같은 정보 창이 열린다.

- `lib.rs`: `menu-about-help` id로 메뉴 항목을 하나 더 만들어 Help 서브메뉴에 넣는다. 메뉴 항목은 한 메뉴에만 속할 수 있어 같은 id를 쓸 수 없어 id가 다른 복사본을 만들고, `on_menu_event`에서 웹뷰로 보낼 때 "menu-about"으로 변환한다.
- Help 서브메뉴가 비어 있으면 구분선 없이 항목만 넣는다 (기본 macOS 메뉴는 Help가 비어 있다).

## 결과

Help → PING9에 관하여, PING9 → PING9에 관하여 두 길 모두 같은 정보 창을 연다.

## 검증

- `cargo check` 통과.
- 릴리스 빌드 후 System Events로 Help 메뉴 항목 확인.
