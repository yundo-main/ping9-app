## 1. 목표와 완료 기준

- [x] 종류가 Server인 PC는 이글루가 아니라 다른 실루엣(세워 둔 랙)으로 보인다
- [x] 장비 목록에 **Server 버튼이 따로 있다** — 끌어 놓으면 OS가 Server인 PC가 놓인다 (inspector에서 OS를 고르는 두 단계가 한 단계로)
- [x] 터미널 창의 종류 칩도 Server PC는 "Server"로 표시한다
- [x] 장비 목록의 네모 버튼(device-tool)이 작아졌다
- [x] 캔버스의 장비 아이콘이 50×50 → 32×32으로 줄어든다. 장비 이름과의 간격과 카드(클릭 영역)는 그대로
- [x] 방패 배지(필터 규칙을 건 서버)는 랙 위에 그대로 단다
- [x] 공통 완료 조건: lint, 타입 검사, 단위 테스트 (4절)
- [ ] 리뷰 — 팀원 검토 없이 main에 커밋했다

## 2. 진행 방식

1. Server는 지금까지 이글루 문 위에 작은 선반을 얹은 "임시 그림"(T0.20 주석 그대로)이었다 — 작게 보면 PC와 구별이 안 된다는 담당 지적.
2. 이글루(집 = PC가 사는 곳)와 실루엣이 다른 **세워 둔 랙**을 그렸다: 둥근 지붕 대신 세로 상자에 검은 서랍 셋, 초록 불빛. 시안의 은유(펭귄이 사는 집 vs 기계가 든 선반)를 살린다.
3. 아이콘은 50 → 32를 거쳐 **32**로. 가운데(x=40)와 바닥선(아래 끝=53)은 고정해 이름 라벨과의 간격을 유지했다. 끌어 놓기 미리보기도 32로 맞췄다.
4. 장비 목록에 Server를 따로 뒀다: 목록의 종류(`PaletteKind = DeviceKind | "server"`)만 가상으로 넓히고, 놓을 때 `device/add`는 `pc`로, 바로 뒤 `pc/set-os server`를 보낸다 — **문서 스키마는 손대지 않았다.** 터미널 창의 종류 칩도 Server로 나온다.
