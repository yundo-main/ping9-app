## 2. 진행 방식

1. Server는 지금까지 이글루 문 위에 작은 선반을 얹은 "임시 그림"(T0.20 주석 그대로)이었다 — 작게 보면 PC와 구별이 안 된다는 담당 지적.
2. 이글루(집 = PC가 사는 곳)와 실루엣이 다른 **세워 둔 랙**을 그렸다: 둥근 지붕 대신 세로 상자에 검은 서랍 셋, 초록 불빛. 시안의 은유(펭귄이 사는 집 vs 기계가 든 선반)를 살린다.
3. 아이콘은 50 → 30. 가운데(x=40)와 바닥선(아래 끝=53)은 고정해 이름 라벨과의 간격을 유지했다. 끌어 놓기 미리보기도 56 → 34로 비례 축소.
