## 1. 목표와 완료 기준

File → 가져오기로 연 파일의 **파일명**이 상단 막대의 토폴로지 이름이 된다.

- [x] `랩.ping9.json`을 열면 이름 칸에 "랩"이 뜬다
- [x] 파일명에서 이름을 만들 수 없으면(`.json`만 있는 파일 등) 파일 안의 `name`으로 되돌린다
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드)

## 2. 진행 방식

기존에는 파일 안에 저장된 `name`(내보낼 때의 이름)을 그대로 썼다 — 파일을 다른 이름으로 저장하면 옛 이름이 떴다. `topology-file.ts`에 `importNameOf(fileName, embeddedName)`를 두고 `.json`→`.ping9` 순으로 꼬리를 떼 파일명 줄기를 쓰되, 비면 파일 안의 이름으로 되돌린다. `app.tsx`의 `importTopology`만 바꾸면 돼 교체 절차는 그대로다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 파일명 우선, 파일 안 이름은 폴백 | 파일 관리자에서 바꾼 이름이 곧 사용자의 의도 | 파일 안 이름 우선 — 이전 동작, 요청과 반대 |

## 3. 변경 내용

| 파일 | 변경 |

| `apps/web/src/topology-file.ts` | `importNameOf` 추가 |
