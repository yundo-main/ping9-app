## 1. 목표와 완료 기준

- [x] 클라우드 포트 이름을 `Port0–2`에서 `FastEthernet0–2`로 바꾼다
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드)

## 2. 진행 방식

1. `PORT_NAMES.cloud`를 `FastEthernet0/1/2`로 바꿨다 — 라우터(Gi0/x)·스위치(Fa0/x)와 같은 장비 포트 명명 규칙을 따르게 됐고, `shortPortName`이 자동으로 `Fa0` 표기를 쓴다.
2. 클라우드 내부 구조 창의 노드 라벨이 `Port{index}` 하드코딩이던 것을 실제 포트 이름(`view.ports[].name`)으로 바꿨다 — 이름이 길어져도 그대로 보인다.
3. 모델·인스펙터·링크 규칙은 전부 `PORT_NAMES.cloud` 기준이라 추가 수정이 없다. 테스트의 링크 포트 문자열과 설명서 예제를 새 이름으로 고쳤다.
