## 2. 진행 방식

1. `PORT_NAMES.cloud`를 3개로 줄였다 — 모델·인스펙터·내부 창이 전부 `PORT_NAMES.cloud` 기준으로 돌아 포트 정의 한 곳만 바꾸면 된다.
2. 내부 구조 창을 K4(정사각 4노드)에서 K3(삼각 3노드)로 다시 그렸다 — R0·R1이 위, R2가 아래 가운데. 꼬리는 위쪽 두 포트는 사선 위로, 아래 포트는 수직 아래로 뻗는다.
3. 구름 중앙에 `1.0.0.0/8`을, 각 꼬리 선 위에 `{링크망}/30`을 넣었다 — 노드 아래 `Port{i} · {클라우드IP}`, 상대 상자의 `{피어IP}`와 함께 링크의 양 끝 주소가 전부 보인다.
4. 테스트의 `cloudPortInfo(3)` 단언을 인덱스 2로, 설명서의 "Port0–Port3 네 개"를 세 개로 고쳤다.
