# T0.51 — 로고가 About을 열고 `i` 버튼 제거

## 한 일

상단 막대 오른쪽의 `i` 버튼을 지웠다. 로고(브랜드)는 T0.41 때부터 `onAbout`이 있으면 "PING9에 관하여"를 여는 버튼이었으므로, `i`는 같은 창을 여는 두 번째 길일 뿐이었다 — 지워도 기능 손실이 없다.

정보 창을 여는 남은 길: 상단 로고, 메뉴바 PING9 → PING9에 관하여, Help → PING9에 관하여, 도움말 창 아래의 "PING9에 관하여" 링크.
