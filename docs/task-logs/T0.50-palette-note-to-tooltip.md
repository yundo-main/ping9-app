# T0.50 — "장비" 제목에 툴팁, 아래 안내 문구 정리

## 한 일

팔레트 바닥에 항상 있던 "장비를 끌어서 배치" 문구를 없애고, "장비" 제목에 올렸을 때 같은 내용의 툴팁이 뜨게 했다.

- `palette.tsx`: `NOTE.idle`을 빈 문자열로 — 평소에는 안내 문구가 안 나온다. `h4`에 `data-tip`을 달았다.
- `editor.css`: 툴팁 규칙을 `.tool[data-tip]`에서 `.palette h4[data-tip]`까지 넓혔다. `.palette-note`에 `min-height: 15px` — 문구가 없어도 자리를 유지해, 끌기 취소 안내가 나타날 때 목록이 밀리지 않는다.
- 장비와 도구 절 사이에 구분선을 넣었다 — 두 번째 `h4` 위에 `border-top`.
- 끌기 취소 중("여기로 가져오면 취소" / "놓으면 취소돼요")에는 문구가 그대로 나온다 — 이 안내는 취소 경로의 표시라 남겼다.

## 결과

평소 팔레트는 "장비" 제목 아래 안내 줄 없이 깔끔하고, "장비"에 올리면 "장비를 캔버스로 끌어서 배치하세요"가 뜬다. 장비를 끌어 목록 위로 가져가면 취소 안내가 같은 자리에 나타난다.
