# T0.48 — 팔레트 버튼 마우스오버 툴팁

## 한 일

장비 목록·도구의 모든 버튼에 마우스를 올리면 오른쪽에 바로 뜨는 툴팁을 넣었다.

- `palette.tsx`: `title` 속성을 `data-tip`으로 바꾸고 장비별 설명(`TIPS` 사전)을 달았다. 네이티브 `title` 툴팁은 뜨기까지 지연이 있고 모양을 고를 수 없어 CSS 툴팁으로 했다.
- `editor.css`: `.tool[data-tip]::after` — 버튼 오른쪽에 어두운 말풍선으로 뜬다. `:hover`와 `:focus-visible`(키보드 초점) 둘 다 반응하고, 꺼진 버튼(`:disabled`)에서는 안 뜬다.

툴팁 내용은 "끌어서 배치 — <장비 설명>" 형태로, 바닥의 안내 문구(장비를 끌어서 배치)가 버튼별 설명으로 나뉜 셈이다. 선택·케이블 도구에도 각각 쓰는 법을 달았다.

## 결과

PC·Server·Switch(묶음·펼침 항목 포함)·Hub·Router와 선택·케이블 버튼에 올리면 각각 무엇인지와 쓰는 법이 뜬다.
