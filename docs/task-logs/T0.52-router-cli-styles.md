# T0.52 — 라우터 팔레트 묶음과 CLI 형식 배지

## 한 일

라우터를 스위치와 같은 묶음 버튼으로 바꾸고, 아이콘에 CLI 형식 배지를 달았다.

- `palette.tsx`: "Router" 버튼을 누르면 플라이아웃에 `Router (IOS)` · `Router (VyOS)` · `Router (Linux)`가 뜬다. 어떤 걸 끌어 놓느냐로 처음 CLI 형식이 정해지고, 배치한 뒤에는 인스펙터의 "라우터 CLI 형식"으로 바꾸는 기존 방법도 그대로다.
- `app.tsx`: 팔레트 드래그에 `cliStyle`을 같이 실어(`dragCliStyle`), `device/add` 성공 직후 `router/set-cli-style`을 보낸다. 기본 ios는 문서에 저장하지 않는다. 배치 안내 줄은 "Router (VYOS)를 원하는 위치에 놓으세요"처럼 형식을 보여준다.
- `device-icons.tsx`: `cliStyle` prop — 라우터 아이콘 오른쪽 아래에 `IOS`·`VyOS`·`Linux` 배지. `LayerBadge`는 글자 수가 많으면 알약을 넓힌다(Linux는 16px). 캔버스 장비·배치 미리보기·플라이아웃 항목에 모두 적용된다.

## 결과

장비 목록은 PC · Server · Switch · Hub · Router 다섯 버튼 그대로이고, Router를 누르면 세 CLI 형식을 고른다. 캔버스의 라우터 아이콘이 `cliStyle`에 따라 다른 배지를 달아 어느 형식인지 바로 보인다.

## 검증

- `pnpm check`: 전체 통과 (shared 470 / engine 1895 / web 647). 묶음 구조에 맞게 팔레트 버튼 수 기대값 3곳 갱신.

fontSize 4.8→6.2, 알약 높이 7→9, 폭은 글자 수별 10/16/21. 라우터뿐 아니라
