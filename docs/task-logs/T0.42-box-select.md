# T0.42 — 캔버스 범위 선택과 묶음 삭제

## 한 일

드래그 선택이 없어 장비를 하나씩 지워야 하던 것을 고쳤다. **Shift+드래그**로 상자를 그려 여러 장비·케이블을 함께 고르고 한 번에 지운다. 평소 드래그는 여전히 캔버스 패닝이다.

- `canvas-interaction.ts` `boxContents()`: 장비는 자리 점이, 케이블은 중점이 상자 안이면 고른다 (테스트 1개 추가).
- `canvas.tsx`: Shift+빈 곳 누르기 → 패닝 대신 `marqueeRef` 추적, 상자를 `.marquee` rect로 그리고 놓으면 `onBoxSelect`에 담긴 id 목록을 올린다. `selectedDeviceIds`/`selectedLinkIds` 집합으로 복수 선택의 빛(sel/selected)을 입히고, ⌘/Ctrl/Shift+누르기는 `onToggleDevice`/`onToggleLink`로 하나씩 넣고 뺀다.
- `app.tsx`: `boxSel` 상태. 하나만 걸리면 평소 하나 고르기로 변환해 속성 패널이 그대로 뜬다. 둘 이상이면 오른쪽에 "N대의 장비와 M개의 케이블" 묶음 패널(모두 지우기/선택 해제). 지울 때 케이블이 딸렸으면 한 번 묻고(`ConfirmDialog`), `device/remove`가 연결 링크까지 지우므로 장비마다 디스패치하면 된다.
- Delete 키: 묶음이 있으면 묶음을 지운다. T1.3.3 규칙 유지 — 고르지 않은 것에 포커스가 있으면 지우지 않고 그것을 먼저 고른다.
- 빈 곳 누르기·Esc·내보내기 교체·하나 고르기는 묶음을 푼다.
- `help-dialog`: 단축키 절에 Shift+드래그와 ⌘/Ctrl+누르기 추가.
