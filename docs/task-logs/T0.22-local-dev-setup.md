## 2. 진행 방식

1. `node --version` 확인 → 시스템은 Node 26, 프로젝트는 `>=24.19 <25` 요구
2. 버전 관리자(nvm, fnm, mise, volta)가 없어 `brew install node@24`로 설치 (keg-only)
3. `corepack enable`로 `packageManager` 필드의 pnpm 12.16.1 활성화
4. `pnpm install --frozen-lockfile` → `pnpm dev`로 Vite 서버 확인 (포트 5173 점유로 5174, HTTP 200)
5. 실행 명령과 디렉터리 구조·역할을 `README.md`에 정리

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| Homebrew `node@24` | 이미 brew로 node를 관리 중, 별도 버전 관리자 도입 불필요 | nvm/fnm 설치 |
| keg-only 유지, PATH로 선택 | 시스템 `node`(26)를 그대로 두고 이 프로젝트만 24 사용 | `brew link node@24`로 전역 교체 |
