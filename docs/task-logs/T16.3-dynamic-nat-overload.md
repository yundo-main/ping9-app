## 1. 목표와 완료 기준

T16.2의 `ip nat inside/outside` 묵시적 masquerade에 시스코식 동적 NAT와 overload(PAT)를 얹는다.

- [x] `ip nat pool <name> <start> <end> netmask <mask>`로 주소 풀을 만들고 지운다
- [x] 표준 번호 ACL `access-list <1-99> permit|deny <net> <wildcard>`(`any`·`host` 포함)로 출발지를 가른다
- [x] `ip nat inside source list <acl> pool <name>` — 풀 주소를 1:1로 배정하는 동적 NAT
- [x] `ip nat inside source list <acl> pool <name> overload` — 풀 주소를 포트로 나눠 쓰는 PAT
- [x] `ip nat inside source list <acl> interface <iface> overload` — 인터페이스 주소로 PAT
- [x] linux는 `iptables -t nat -A POSTROUTING -s <net> -o <eth> -j SNAT --to-source a-b` / `-j MASQUERADE`, vyos는 `nat source rule`의 범위 `translation address`·`translation port`로 표현한다
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드, 리뷰)

## 2. 진행 방식

1. shared에 `NatPool`·`AccessListEntry`·`NatSourceRule`과 명령 5개(`set-nat-pool`, `set-access-list`, `remove-access-list`, `set-nat-source`, `remove-nat-source`) 추가.
2. `RouterModel`에 규칙 평가를 넣었다: `natSources`가 비어 있으면 기존 묵시적 masquerade(하위 호환), 있으면 ACL/직접 매칭을 허락한 첫 규칙만 변환하고 어느 규칙도 안 맞으면 변환 없이 보낸다.
3. 풀 주소 배정은 `#natAddr`(insideIp→주소)와 `#natAddrByIp`(주소→대응) 두 색인. overload이 아니면 포트를 바꾸지 않는 1:1 대응이라 `show ip nat translations`에 포트 없는 줄로 보인다. overload이면 주소 배정 위에 기존 PAT 바인딩을 쌓는다 — `NatBinding`에 `outsideIp`를 넣고 바깥 색인 키에 포함시켰다.
4. `ArpModule`에 `ownsIp` 훅을 추가해 라우터가 NAT 주소(풀 범위·정적 outside)에 proxy ARP로 답한다 — 풀이 외부 링크의 같은 서브넷에 있을 때 필요한 실제 IOS 동작이다.
5. vyos는 `source address`(CIDR)가 규칙의 매칭을 직접 담고 `translation address a-b` 범위가 풀이므로, `NatSourceRule`에 `network`·`wildcard`·`poolStart`·`poolEnd` 직접 필드를 열어 listId 없이 표현했다. overload는 `translation port 1-65535` 잎으로 왕복한다.
6. linux는 `-s <net>`이 매칭, `--to-source a-b`가 인라인 풀, `-o ethN`이 egress이자 outside 표시의 근거다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| `natSources`가 비어 있으면 기존 묵시적 masquerade 유지 | 기존 문서·테스트·linux masquerade와의 호환 — `ip nat outside`만으로도 동작하던 것이 깨지면 안 된다 | 빈 규칙 = 변환 없음(실제 IOS와 같지만 기존 저장을 깸) |
| 규칙이 출발지를 허락하지 않으면 변환 없이 통과 | 실제 IOS의 "no matching NAT rule"과 같다 — 패킷은 죽지 않고 원래 주소로 나간다 | 드롭(실제와 다름) |
| 풀 overload 고갈 시 첫 주소 공유 | Cisco는 풀 주소를 호스트별로 배정하다가 포트가 닳으면 나눠 쓴다 | 규칙당 주소 하나 고정(더 단순하지만 실제와 멂) |
| 바깥 색인 키에 `outsideIp` 포함 | 서로 다른 풀 주소의 natPort가 겹칠 수 있다 | 전역 카운터만으로 구분(충돌 가능) |
| vyos `translation port 1-65535`로 overload 왕복 | VyOS 실제 문법이고 정보가 보존된다 | 주석·불리언 필드(설정 문법이 아님) |
