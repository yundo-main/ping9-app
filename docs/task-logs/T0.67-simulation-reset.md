## 1. 목표와 완료 기준

토폴로지를 유지한 채 시뮬레이션 상태(추적·배운 테이블)를 처음으로 되돌리는 버튼.

- [x] `simulator.resetSimulation()` — Runtime 전체 reset + RIP 재교환
- [x] 상단 막대에 ⟲ 리셋 버튼 (두 모드 모두 표시)
- [x] Document·콘솔 세션·파일은 유지

## 2. 진행 방식

1. 엔진 `Simulator`에 `resetSimulation()` 추가 — `runtime.reset()`이 kernel·장비 모델·
   추적을 전부 비운다. RIP Router가 있으면 load와 같은 규칙으로 경로 교환 1회 재실행
2. `runtimeVersion += 1` 후 `changed()` — 구독자(UI)가 빈 추적 목록을 받는다
3. TopBar `onReset` prop + `⟲ 리셋` ghost 버튼 — `?` 도움말 버튼 왼쪽,
   시뮬레이션/실시간 모두에서 보인다 (추적은 두 모드에서 쌓인다)
4. 툴팁에 지워지는 것 명시: "추적·ARP 테이블·배운 경로를 지웁니다 (토폴로지는 유지)"
