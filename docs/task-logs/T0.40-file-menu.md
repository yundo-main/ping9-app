# T0.40 — 메뉴바의 파일 메뉴 (가져오기/내보내기)

## 한 일

데스크톱 앱의 네이티브 메뉴바에 "파일" 메뉴를 넣고, **가져오기…**(`⌘O`)·**내보내기…**(`⇧⌘S`) 항목이 화면의 같은 버튼과 동일한 절차를 타도록 연결했다.

- `apps/web/src-tauri/src/lib.rs`: `Menu::default`로 표준 메뉴(앱·편집·윈도우·도움말)를 만든 뒤, 기본 File 서브메뉴가 있으면 구분선 뒤에 항목을 더하고, 없으면 "파일" 서브메뉴를 앱 메뉴 뒤에 끼운다. `on_menu_event`에서 두 항목을 웹뷰 이벤트 `menu-import`/`menu-export`로 흘린다.
- `apps/web/src/topology-file.ts`: `pickImportFile()` 추가 — Tauri 열기 창(`.json` 필터)으로 고른 파일을 읽어 `File`로 돌려준다. 취소하면 null.
- `apps/web/src/app.tsx`: Tauri일 때만 `listen`으로 두 이벤트를 받아 `importTopology`/`exportTopology`를 호출한다. 리스너는 최신 함수를 ref로 잡아 한 번만 구독한다.
- `apps/web/src-tauri/capabilities/default.json`: `fs:allow-read-text-file` 추가 (열기 창에서 고른 파일을 읽기 위함).
- `@tauri-apps/api`를 직접 의존으로 추가 (이벤트 `listen` API; 플러그인과 같은 2.12.5).

## 검증

- `pnpm check`: shared 470, engine 1894, web 642 — 전부 통과.
- `cargo check`: 통과.
- 메뉴 동작은 Tauri 런타임에서만 확인 가능 — 릴리스 빌드로 메뉴바의 파일 메뉴와 항목 동작을 확인한다.

## 계획과 달라진 점

- 메뉴 항목은 한국어(가져오기…/내보내기…). 기본 메뉴에 이미 File 서브메뉴(Close Window/Close All)가 있어 그 안에 구분선을 두고 넣었다 — 메뉴바에는 "File"로 보인다.
