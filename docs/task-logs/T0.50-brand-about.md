## 2. 진행 방식

T0.41에서 만든 `AboutDialog`와 `TopBar`의 `onAbout` prop은 이미 있고, 상단 막대 오른쪽의
`i` 버튼으로만 열 수 있었다. 요청은 "PING9 아이콘 클릭 → 어바웃"이므로 브랜드 영역
(`.tile` 로고 + `.wordmark`)을 눌러지게 만들면 충분했다.

1. `TopBar`의 `.brand` div를 `onAbout`가 있을 때 `<button class="brand">`로 렌더링하도록 변경.
   `onAbout`가 없으면 기존처럼 눌러지지 않는 `div`로 둔다 (현재 호출부는 항상 넘긴다).
2. `button.brand`의 기본 버튼 스타일을 지우는 CSS와 호버 피드백(로고 밝기) 추가.
3. SSR 렌더 테스트로 마크업 확인: `onAbout` 유무에 따른 button/div 분기와 aria 라벨.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 로고+워드마크 전체를 하나의 버튼으로 | "PING9 아이콘" 영역 어디를 눌러도 동작하는 게 자연스러움. 타깃도 넓어짐 | `.tile` 로고만 버튼으로 |
| `onAbout` 없을 땐 `div` 유지 | prop이 optional이라 "버튼인데 아무 일도 안 함" 상태를 피함 | 항상 button으로 렌더링 |
