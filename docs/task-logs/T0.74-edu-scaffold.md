## 1. 목표와 완료 기준

- [x] `apps/`와 섞이지 않는 최상위 `edu/` 디렉터리로 교육용 앱을 분리한다
- [x] PING9 엔진·공용 패키지를 재사용하는 최소 앱이 빌드된다
- [x] Vercel 프로젝트 연결 방법이 문서화된다
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드)

## 2. 진행 방식

1. `apps/` 형제인 최상위 `edu/app`을 만들고 `pnpm-workspace.yaml`에 `edu/*`를 추가했다 — 본체(`apps/web`)와 시각·배포 모두 분리된다.
2. `edu/app`은 Vite + React 셸 — `EXAMPLE_DOCUMENTS`를 나열하고 `createSimulator()`로 스냅샷을 읽어 엔진 재사용이 도는지 확인하는 최소 화면. 분리 규칙으로 `apps/web` import 금지를 `edu/README.md`에 명시했다.
3. `edu/app/vercel.json` — Vite 프레임워크, `pnpm --filter @ping9/edu build`, 출력 `dist`. Root Directory를 `edu/app`으로 잡는 Vercel 대시보드 설정 절차는 `edu/README.md`에 적었다.
4. README 구조 표에 `edu/app` 행을 추가했다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 최상위 `edu/` 디렉터리 | `apps/edu`는 본체와 같은 폴더에 섞여 구분이 안 된다는 요청에 따라 형제 디렉터리로 분리 | `apps/edu`, 별도 저장소 |
| 같은 저장소 유지 | 별도 저장소는 엔진 동기화(발행·서브모듈)가 번거롭다 — 배포만 분리하고 코드는 공유 | 별도 저장소 |

## 3. 결과와 검증
