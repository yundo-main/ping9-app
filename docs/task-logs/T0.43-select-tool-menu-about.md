# T0.43 — 선택 도구 버튼 + 메뉴바의 PING9에 관하여

## 한 일

### 선택 도구 (범위 선택 버튼)

Shift+드래그만으론 범위 선택을 발견하기 어려워, 케이블 도구와 같은 토글 버튼을 팔레트에 뒀다. "도구" 절(옛 "연결")의 맨 위 — 점선 상자+커서 아이콘.

- 켜져 있으면 빈 곳의 평소 드래그가 패닝 대신 범위 선택 상자가 된다 (캔버스는 crosshair 커서). 켜져 있는 동안은 패닝이 안 된다 — 끄면 돌아온다.
- 케이블 도구와 배타적: 하나를 켜면 다른 하나는 꺼진다. 장비를 목록에서 끌기 시작해도 꺼진다. Esc로도 꺼진다.

### 메뉴바의 PING9에 관하여

기본 메뉴의 "About PING9"는 네이티브 창이라 개발자 정보가 안 나온다. 앱 메뉴 맨 위의 그 항목을 지우고, 같은 자리에 커스텀 "PING9에 관하여"를 둬 `menu-about` 이벤트로 T0.41의 정보 창을 연다.

- `src-tauri/src/lib.rs`: 메뉴 서브메뉴들을 돌며 텍스트가 "About"으로 시작하는 Predefined 항목을 찾아 `remove`하고 `insert(0)`로 커스텀 항목을 넣는다.

## 검증

- `pnpm check`: shared 470, engine 1894, web 645 — 전부 통과 (팔레트 버튼 수 검증 6→7 갱신).
- `cargo check` 통과. 앱의 PING9 메뉴 첫 항목이 "PING9에 관하여"임을 실행 중인 앱에서 확인했다.

## 계획과 달라진 점

- 선택 도구가 켜진 동안 빈 곳 드래그로 패닝할 수 없다 — 토글이라 불편은 작다고 판단 (T0.42와 같은 상자 동작).
- "연결" 절 이름을 "도구"로 바꿨다 — 선택은 연결이 아니라서.
