## 1. 목표와 완료 기준

## 2. 진행 방식

1. 내비 — sticky + backdrop blur, 로고·wordmark·우측 링크(설명서·히스토리·GitHub)
2. 히어로 — 파랑/초록 이중 radial 그라데이션, 로고 drop-shadow, h1 그라데이션 텍스트,
   버튼 호버 리프트, "v1.0.0 · 계정 없이 바로 실습" 모노 버전 줄
3. 기능 카드 — 흰 배경 + 소프트 그림자, 호버 시 들림, 앞에 인라인 SVG 아이콘 칩(파랑/초록)
4. 펭귄 일러스트를 "교실에서 바로 쓰는 실습 도구" 2열 절로 재배치 — 불릿 3개 + 수치 스트립(8종 장비·3가지 CLI·5개 서비스)
5. 맛보기를 라이트 페이지 안의 다크 터미널 카드로 — macOS 창 점 + 프롬프트 초록 + 주석 회색
6. 문서 카드를 링크 카드로 재구성 — 제목·설명·"문서 보기 →" 3줄 (예전 "설명 — 링크" 한 줄 방식 교체)
7. 히스토리 — 생성 스크립트를 두 구역으로 분리: 최근 12행 표시 + 나머지는
   `<details>` 안 표. `update-landing-history.mjs`가 `HISTORY`·`HISTORY-MORE` 두 표시를 갱신
