## 2. 진행 방식

1. `tauri.conf.json`의 `bundle.icon`을 읽어 실제 참조 아이콘 5개(`32x32`, `128x128`, `128x128@2x`, `icon.icns`, `icon.ico`)를 확인한 뒤 나머지를 `git rm`.
2. Square*Logo·StoreLogo는 Windows Store(msix/appx) 전용 — 이 프로젝트는 nsis·msi만 만들어서 쓸 일이 없다. `icon.png`·`64x64.png`는 설정에 없는 잉여본.
3. 원격 브랜치는 `git push origin --delete`로 일괄 삭제 — 전부 병합된 PR 브랜치라 이력은 main에 보존된다.
4. `.claude/`는 **유지했다** — 안의 bmad 스킬들이 현재 세션에서 실제로 로드돼 쓰이는 도구 디렉터리이기 때문.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| `.claude/` 유지 | `.claude/skills/bmad-*`가 이 세션에서 실제 로드되는 스킬 — 지우면 도구가 깨진다 | gitignore로 숨김(팀 공유 목적으로 추적 유지가 낫다고 판단) |
| 모바일·MSIX 아이콘 삭제 | 데스크톱만 배포, 설정도 참조 안 함 | 남겨둠(앱 크기엔 영향 없지만 저장소 정리 목적에 반함) |
| 아이콘 크기 자체는 유지 | `icon.icns` 1.6MB는 앱에서 실제 쓰는 파일 — 압축하면 품질 손실 우려 | icns 재압축 |
