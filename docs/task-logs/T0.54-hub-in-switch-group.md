# T0.54 — Hub를 스위치 묶음 안으로

## 진행 방식과 결과

사용자 요청: 팔레트의 Hub 버튼을 스위치 묶음 플라이아웃 안에 넣고, 계층을 붙여 표시한다.

- `components/palette.tsx`: 맨 아래 `{tool("hub", "Hub")}`를 지우고 플라이아웃 맨 위에
  `{tool("hub", "L1 Hub")}`를 넣었다. 순서를 계층 순으로 맞췄다 —
  L1 Hub · L2 Switch · L3 Switch · LB. 플라이아웃의 aria-label은 "스위치·허브 종류"로 바꿨다.
- 이름은 "L0"가 아니라 **L1**로 잡았다 — 허브는 물리 계층(OSI 1계층) 장비라
  아이콘의 "L1" 배지와 일치해야 해서다. 사용자가 L0를 원하면 즉시 바꿀 수 있다.
- 아이콘 배지(`device-icons.tsx`의 hub "L1")는 변경 없음.

## 검증

`pnpm check` 전체 통과 — shared 470 · engine 1898 · web 647.

## 계획과 달라진 점

- Hub가 이제 묶음 플라이아웃 항목이라 상위 장비 버튼이 2개(PC, Server)로 줄고
  묶음 버튼 2개(Switch, Router)만 남는다. 닫힌 상태 버튼 수 7→6, draggable 3→2.
- 테스트 갱신: router.test.tsx(버튼·disabled·aria-label 기대값), server-filter.test.tsx
  (device-tool 수), port-picker.test.tsx(draggable 수).
