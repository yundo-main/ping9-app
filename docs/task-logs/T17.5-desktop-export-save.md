## 1. 목표와 완료 기준

데스크톱 앱에서 "⤓ 내보내기"가 동작하지 않는 문제를 고친다.

- [x] Tauri 웹뷰에서 누르면 macOS 저장 창이 뜨고, 고른 자리에 `.ping9.json`을 쓴다
- [x] 브라우저(`pnpm dev`)에서는 기존 다운로드 동작 그대로
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드, 리뷰)

## 2. 진행 방식

1. 원인: `downloadText`가 `Blob`+`<a download>`를 쓰는데, Tauri 웹뷰(WKWebView)에는 브라우저의 다운로드 흐름이 없어 눌러도 아무 일도 안 일어났다.
2. `tauri-plugin-dialog`(저장 창)과 `tauri-plugin-fs`(파일 쓰기)를 Rust·JS 양쪽에 추가했다 — 대화상자에서 고른 경로는 플러그인이 자동으로 fs 범위에 넣어 준다.
3. `downloadText`를 `async`로 바꾸고 `__TAURI_INTERNALS__` 유무로 갈렀다 — 브라우저 경로는 그대로, Tauri면 동적 `import`로 플러그인을 불러 `save` → `writeTextFile`. 동적 import라 웹 번들 테스트에도 영향 없다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 공식 dialog·fs 플러그인 | Tauri v2의 표준 방법 — 권한(capabilities)도 공식 permission 이름으로 준다 | `rfd` 크레이트로 자체 명령(플러그인과 같은 일을 직접 함) |
| `__TAURI_INTERNALS__` 검사 | Tauri가 웹뷰에 넣는 내부 전역 — 플러그인은 로드 전이라 이걸로 분기 | `window.__TAURI__`(v2에서 기본 노출이 아닐 수 있음) |
| 동적 `import()` | 브라우저에서 실행할 때 플러그인을 해석하러 가지 않게 | 정적 import(데스크톱 전용 모듈을 웹 번들에 억지로 묶음) |
