# T0.44 — 화면의 포트 이름 줄임 표기 확장

## 한 일

인스펙터·링크 패널·포트 선택 창에 남아 있던 전체 포트 이름을 `shortPortName`의 줄임 표기(`Fa0/1`, `Gi0/0`, `Eth0`, `P0`, `e0`)로 통일했다. Document와 Command는 그대로 전체 이름을 쓴다 (AD-9 — 표시만 줄인다).

- `link-inspector.tsx`: 링크 양 끝 포트 이름.
- `port-picker.tsx`: 포트 고르기 버튼들.
- 되돌린 곳: `pc-settings.tsx`·`server-settings.tsx`의 `PortSwitch` — 여기의 `port`는 Document 포트가 아니라 OS 라벨(`eth0`/`Ethernet0`)이라, `e0`으로 줄이면 리눅스 실제 인터페이스 이름이 가려진다. 그대로 둔다.
- `events.ts`의 `PORT_CLOSED` 등은 이미 `p()` 도우미로 줄여서 나온다. 서비스 포트 번호(80 등)는 인터페이스 이름이 아니라 그대로.

## 검증

- `pnpm check`: 전부 통과 (web 645). 포트 선택 창·링크 패널 테스트를 줄임 표기 기대로 갱신 — 링크 패널의 "양 끝 전체 포트 이름" 테스트는 "양 끝 포트 이름"으로 이름도 바꿨다.

## 계획과 달라진 점

- OS 라벨(eth0 등)은 축약 대상에서 제외 — 실제 OS의 인터페이스 이름이라 줄이면 오히려 틀리다.
