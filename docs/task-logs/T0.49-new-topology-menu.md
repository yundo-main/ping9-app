# T0.49 — 파일 메뉴에 새 토폴로지

## 한 일

File 메뉴에 "새 토폴로지"(⌘N)를 넣어 캔버스를 빈 문서로 되돌리게 했다.

- `lib.rs`: `menu-new` 항목(⌘N)을 File 서브메뉴의 가져오기/내보내기 앞에 넣고, 웹뷰로 `menu-new` 이벤트를 보낸다.
- `app.tsx`: `newTopology`는 `EMPTY_DOCUMENT`로 바꾼다. 캔버스에 장비가 있으면 가져오기와 같은 "바꿀까요?" 대화상자를 띄운다 — `PendingImport.fileName`을 null 허용으로 바꿔, null이면 "새 토폴로지를 만들면 지금 캔버스의 장비와 케이블이 사라져요"로 문구를 고른다. 이름은 `TOPOLOGY_NAME`(기본 "새 토폴로지")으로 돌아간다.

## 결과

File → 새 토폴로지 (⌘N): 빈 캔버스면 바로 초기화, 장비가 있으면 확인 후 초기화. 가져오기와 같은 교체 절차(선택·터미널·재생 상태 초기화)를 탄다.
