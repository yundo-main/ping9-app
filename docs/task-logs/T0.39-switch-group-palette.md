# T0.39 — 장비 목록의 스위치 묶음

## 한 일

팔레트의 스위치류 세 항목(L2 Switch, L3 Switch, LB)을 "Switch" 묶음 버튼 하나로 접었다. 버튼을 누르면 팔레트 **옆에 뜨는 플라이아웃**에서 세 도구 중 하나를 끌어 놓는다 — 팔레트 자체의 크기는 변하지 않는다. LB는 L4·7 스위치라 묶음에 넣었고, 허브·라우터·PC·서버는 그대로 낱개 버튼이다.

- `apps/web/src/components/palette.tsx`: `useState`로 묶음의 펼침 상태를 둠. 묶음 버튼은 `aria-expanded`와 화살표(▸/◂)를 표시하고, 펼친 도구는 `.switch-flyout` 안에 담는다. 도구 버튼 생성을 `tool()` 헬퍼로 묶었다.
- `apps/web/src/components/device-icons.tsx`: `hideLayerBadge` prop 추가 — 묶음 버튼은 한 계층을 뜻하지 않으므로 스위치 아이콘을 배지 없이 그린다.
- `apps/web/src/styles/editor.css`: `.tool-group`(기준 박스), `.group-tool`, `.group-caret`, `.switch-flyout` 스타일. 플라이아웃은 `position: absolute`로 팔레트 오른쪽에 겹쳐 띄우고 크기·카드 모양을 팔레트와 맞춘다.

## 검증

- `pnpm check`: shared 470, engine 1894, web 642 — 전부 통과.
- 회귀로 고친 테스트: 팔레트 버튼/라벨 개수 검증(router.test, server-filter, port-picker) — 장비 도구 7개가 도구 4개 + 묶음 1개로 바뀐 것을 반영.
- `renderToString`은 초기 상태만 그리므로 묶음의 펼침 동작 자체는 테스트하지 않고, 접힌 상태의 버튼 구성만 검증한다.

## 계획과 달라진 점

- 묶음은 기본으로 접혀 있다 — "눌러서 고른다"는 요청에 맞춰 `useState(false)`.
- 처음에는 펼친 도구를 팔레트 안에 들여쓰기로 넣었으나, 목록이 커진다는 피드백을 받아 팔레트 옆 플라이아웃으로 바꿨다.
