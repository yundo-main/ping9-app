## 1. 목표와 완료 기준

앱 안에서 사용법을 볼 수 있는 도움말을 만든다 — 터미널의 `?` 명령 도움말과 별개로, 처음 여는 사람이 화면 사용법을 알 수 있는 창.

- [x] 상단 막대에 `?` 버튼
- [x] 누르면 사용법 대화상자 — 시작하기·콘솔·스타일·시뮬레이션·단축키
- [x] 닫기 버튼·Esc·바깥 클릭으로 닫힘
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드, 리뷰)

## 2. 진행 방식

1. 확인창(`ConfirmDialog`, T7.1.2)과 같은 모달 패턴: 같은 배경 클래스를 재사용하고, 본문만 스크롤되는 조금 더 큰 창으로 만들었다.
2. 내용은 실제 구현된 기능만 실었다 — 팔레트 드래그, 케이블 도구, Inspector, 각 콘솔의 명령(ios/linux/vyos·NAT 포함), 시뮬레이션 재생, 단축키.
3. `TopBar`에 선택 prop `onHelp`를 추가해 모드 탭 왼쪽에 `?` 버튼을 두었다 — prop이 없으면 그리지 않아 기존 호출(테스트 포함)이 그대로 통과한다.
4. Esc는 app.tsx의 기존 전역 Esc 처리기에 `setHelpOpen(false)` 한 줄을 얹었다 — 케이블 해제·확인창 닫기와 같은 자리.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 별도 `help-dialog.tsx` | 내용이 길고 순수 표시용 — TopBar·app을 무겁게 만들지 않는다 | TopBar 안에 인라인 |
| `ghost` 클래스 안 씀 | 내보내기·가져오기와 무리를 지으면 top-bar 테스트의 버튼 목록 단언이 깨진다 — `help-open`이라는 전용 클래스로 분리 | `.file-actions` 안에 `ghost` 버튼(테스트 깨짐) |
| 내용 하드코딩 | 도움말은 고정 문구 — 문서 파일을 불러오는 구조는 과함 | 마크다운 로딩 |
