## 1. 목표와 완료 기준

서버 속성 패널에서 서비스 스위치를 켰을 때, 그 서비스의 설정 구역이 어디 있는지 사용자가 바로 알게 한다.

- [x] 스위치를 켜면 해당 서비스의 설정 제목으로 부드럽게 스크롤된다
- [x] 제목이 잠시 밝게 강조된다
- [x] 끌 때는 아무 일도 일어나지 않는다
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드)

## 2. 진행 방식

사용자 질문으로 "서비스 스위치 켤 때 설정으로 이동"을 확인했다(아코디언·서비스 탭 후보는 기각). 스위치 `onChange`에서 dispatch 후 `SERVICE_SECTION` 매핑으로 구역 id를 찾아 `scrollIntoView` + flash 클래스를 준다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| `scrollIntoView({ block: "nearest" })` | 이미 보이면 스크롤이 튀지 않는다 | `block: "start"` — 항상 맨 위로 끌어가 산만함 |
| 제목(h4)만 강조 | 구역 전체를 칠하면 폼 입력까지 배경이 번쩍인다 | 구역 래퍼에 테두리 |
