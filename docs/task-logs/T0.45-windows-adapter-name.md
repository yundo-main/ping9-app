# T0.45 — Windows 포트 이름을 "로컬 영역 연결"로

## 한 일

Windows PC의 포트 표시 이름을 한국어 Windows의 실제 어댑터 이름 "로컬 영역 연결"로 바꿨다. Document·Command가 쓰는 포트 이름(`Ethernet0`)은 그대로다 — 바뀐 것은 화면·콘솔 출력의 표시뿐.

- `pc-settings.tsx`, `server-settings.tsx`의 `PORT_LABELS.windows`: `PC_PORT`("Ethernet0") → `"로컬 영역 연결"`. PortSwitch의 `aria-label`도 "포트 로컬 영역 연결"이 된다. Linux는 `eth0` 유지.
- `pc-commands.ts`의 `ipconfig`·`ipconfig /all` 출력: `Ethernet adapter Ethernet0:` → `Ethernet adapter 로컬 영역 연결:` — 실제 Windows ipconfig가 어댑터 이름을 이렇게 보여준다.

## 결과

Windows PC/서버의 포트 스위치와 `ipconfig` 출력이 실제 Windows와 같은 어댑터 이름을 쓴다.
