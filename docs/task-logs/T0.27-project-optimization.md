# T0.27 프로젝트 최적화 (계획에 없는 새 ID)

## 1. 무엇을 했는가

코드가 아니라 프로젝트의 죽은 무게를 덜었다.

- **`pnpm-workspace.yaml` 카탈로그 정리**: 옛 웹 앱 계획(REST 서버·인증)에서 온 미사용 의존성 16개 제거 — hono·better-auth·drizzle·pg·pino·@xyflow/react·react-router·tailwind·zustand·@xterm·@playwright/test. 어떤 `package.json`도 참조하지 않아 카탈로그만 지우면 된다 (설치물은 원래 없었다).
- **`apps/web/public/mockup.html` 삭제**: 118KB. 화면 시안 사본인데 원본은 `docs/superpowers/specs/2026-11-05-switch-vlan-mockup.html`에 있고 앱에서 참조하지 않는다 — public은 앱에 같이 실려 나간다.
- **`panel-penguin.png` 축소**: 1350×880 → 675px 폭 (inspector 패널이 ~300px이라 레티나 기준으로도 충분). 1.6MB → 0.4MB.
- **vite `chunkSizeWarningLimit: 800`**: Tauri 데스크톱은 산출물이 로컬 파일이라 청크 분할 이득이 없다. 729KB 경고를 끄는 게 아니라 "한 덩어리가 의도"라는 설정으로 바꿨다.
- **릴리스 워크플로에 Rust 캐시**: `Swatinem/rust-cache` (커밋 해시 고정, SEC-27). 다음 빌드부터 크레이트 컴파일 시간이 크게 줄어든다.

## 2. 진행 방식

1. 카탈로그의 각 의존성이 `src/`에서 import되는지 일괄 집계 → 실사용만 남겼다.
2. `public/` 에셋의 참조를 확인 → 미참조 mockup만 삭제. 배경·로고는 CSS와 컴포넌트가 쓰므로 유지.
3. 이미지는 표시 크기의 2배(레티나)로 축소 — sips.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 카탈로그 항목만 삭제 | package.json에서 이미 아무것도 안 씀 — 설치물·잠금파일 영향 없음 | package.json까지 정리 — 이미 깨끗 |
| 청크 경고는 limit 상향 | 데스크톱 앱에서 분할은 의미 없음 — 오히려 파일 수만 늘어난다 | manualChunks 분할 |
| 배경 이미지는 그대로 | 전체 화면 배경이라 축소하면 깨진다. 1.3MB는 데스크톱 기준 작다 | JPEG/WebP 변환 |
