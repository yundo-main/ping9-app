## 1. 목표와 완료 기준

가져오기로 연 파일의 **파일명 그대로**(확장자 포함)가 화면에 보인다. T0.60은 파일명 줄기를 토폴로지 이름으로 쓴 것 — 이건 파일명 표시다.

- [x] `랩.ping9.json`을 열면 이름 옆에 `랩.ping9.json`이 작게 뜬다
- [x] 새 토폴로지면 표시가 없다
- [x] 공통 완료 조건 (lint, 타입 검사, 단위 테스트, 빌드)

## 2. 진행 방식

`PendingImport.fileName`이 이미 파일명을 싣고 있다 — `replaceTopology`에서 `sourceFile` 상태로 옮기고 TopBar의 crumb에 `<span className="file-src">`로 그린다. `fileName: null`(새 토폴로지)이면 지워진다.

### 주요 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 이름 옆 작은 회색 글씨 | 이름 편집과 별개 정보. 눈에 띄되 방해는 안 되게 | 창 제목·배너 — Tauri 창 제목 변경은 껍데기 작업이 필요 |
