## 2. 진행 방식

1. **장비 목록**: "시작하기"의 장비 놓기를 `PC·서버·스위치·L3 스위치·허브·라우터·LB`로 갱신
2. **새 절 "L3 스위치 콘솔"**: `ip routing`, `interface vlan <번호>`(SVI), `no switchport`, `ip route`/`router rip`
3. **새 절 "LB 콘솔 (리눅스)"**: Inspector에서 프런트엔드 편집, L4 DNAT vs L7 프록시, 리눅스 `ip` 명령, `haproxy -c`, 백엔드 세그먼트 조건
4. "콘솔 스타일"의 linux 항목에 LB는 항상 리눅스임을 덧붙였다
